# Audio credits

All sound effects in this folder are **synthesized procedurally in-house**
(lane 2, slice 3) — pure Dart oscillators (sine/square/saw), a seeded LCG
noise source, and exponential envelopes written directly as 16-bit PCM WAV
(22050 Hz, mono). No third-party samples, no CC0 downloads, no attribution
required. Generation script was a one-off tool and is not shipped; the
parameters below fully describe each sound.

| File | Used by event | Synthesis |
| --- | --- | --- |
| `sfx_swap.wav` | `Swapped` | Two 50 ms square blips, 700→900 Hz pitch rise, fast decay |
| `sfx_reject.wav` | `SwapRejected` | 180 ms square buzz, 180→110 Hz fall, decay envelope |
| `sfx_pop.wav` | `Cleared` | 90 ms sine chirp 480→980 Hz + 30 ms noise click; playback rate rises per cascade step |
| `sfx_chime.wav` | `SpecialCreated` | Two sine notes 880 Hz then 1318 Hz, staggered 30 ms, decay |
| `sfx_special.wav` | `SpecialFired` | Three-note rising arpeggio 523/659/784 Hz, 90 ms each |
| `sfx_tick.wav` | `Fell` | 35 ms quiet sine 1400→900 Hz (one per falling piece) |
| `sfx_plip.wav` | `Refilled` | 80 ms sine 320→640 Hz |
| `sfx_thud.wav` | `ObstacleLanded` | 200 ms low sine 110→60 Hz + 80 ms noise thump |
| `sfx_crack.wav` | `ObstacleBroken` | 100 ms seeded noise burst + 120 ms square 220→90 Hz |
| `sfx_ding.wav` | `ObstacleQueued` | 280 ms sine bell at 988 Hz, slow decay |
| `sfx_charge.wav` | `PowerCharged` | 160 ms sine sweep 300→1200 Hz |
| `sfx_power.wav` | `PowerFired` | 300 ms saw sweep 900→120 Hz + 200 ms noise zap |
| `sfx_swish.wav` | `Shuffled` | 320 ms low-passed noise sweep |
| `sfx_bonus.wav` | `ExtraMove` | Two-note happy chime 660→880 Hz |
| `sfx_round.wav` | `RoundEnded` | Three-note sting 523/659/784 Hz |
| `sfx_end.wav` | `MatchEnded` | Four-note fanfare 392/523/659/784 Hz |

Pre-existing `assets/generated/purr.wav` is generated by `tool_assets.dart`
(orchestrator-owned) and is not part of this set.
